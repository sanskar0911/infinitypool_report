\chapter*{Abstract}

Quantitative backtesting of equity trading strategies is a fundamental requirement in systematic finance, enabling researchers and portfolio managers to evaluate the viability of algorithmic trading rules against historical market data before committing real capital. The Indian equity market, particularly stocks listed on the National Stock Exchange (NSE), presents unique opportunities and challenges for systematic strategy development due to its high volatility, diverse sectoral composition, and growing institutional participation.

This project presents the design and implementation of an \textbf{Institutional-Grade Equity Quantitative Backtesting and AI-driven Research Framework} developed as part of the Shankh / Decuple Internship 2026--27 (Project TE1). The framework is built using a modular, production-grade Python architecture that encompasses the complete quantitative research pipeline: historical data ingestion from Yahoo Finance, automated data cleaning and validation, a Strategy Factory Pattern supporting multiple technical analysis strategies (SMA Crossover, EMA Crossover, and RSI), a realistic backtesting execution engine with configurable transaction costs (0.1\%), slippage modeling (0.05\%), fractional position sizing, stop-loss and take-profit triggers, and comprehensive portfolio constraint enforcement including liquidity filtering, maximum position caps, and rebalancing schedules.

The system computes a comprehensive suite of quantitative Key Performance Indicators (KPIs) including CAGR, Sharpe Ratio, Sortino Ratio, Calmar Ratio, Maximum Drawdown, Win Rate, Profit Factor, and Turnover. Strategy performance is rigorously benchmarked against the Nifty 50 index, computing relative metrics such as Excess Return, Beta, Correlation, Tracking Error, and Information Ratio. A complete experiment engine provides systematic parameter sweeps, rolling walk-forward validation, out-of-sample testing with automated look-ahead bias detection, robustness sensitivity analysis, and market regime classification.

A key innovation is the integration of \textbf{LangGraph-based Agentic Loop Engineering}, which implements a controlled research state machine that autonomously evaluates intermediate backtest results against predefined thresholds and iterates with bounded parameter adjustments before producing the final research artifact. The framework also incorporates LLM-driven strategy analysis using structured JSON output schemas. A professional Streamlit web dashboard provides an interactive interface for strategy configuration, KPI visualization, experiment execution, and report generation.
